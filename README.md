# 橘小黑工作台

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 换一套顺眼的配色，并补上几个原生没有的实用入口。

## 特性

### 主题

- **默认薄荷绿 × 纯白** — 50 组深浅色令牌，覆盖界面主要元素
- **跟随系统** — 浅色 / 深色 / 跟随系统，自动切换
- **背景可自定义** — 在设置页调整，一键恢复默认
- **卸载即还原** — 关闭插件后界面立刻回到原生外观

### 功能

| 功能 | 说明 | 默认 |
|---|---|---|
| **账户余额** | 侧边栏底部显示余额，点击展开明细卡片 | 开 |
| **工作区一键运行** | 会话头部快捷操作入口 | 开 |
| **会话快速删除** | 会话列表右键菜单直接删除 | 开 |
| **模型修改样式** | 模型选择器改两行，附推理强度滑块 | 开 |
| **技能市场** | 内置技能浏览与安装 | 开 |
| **隐藏侧栏「更多」** | 收起侧栏面板列表里的「更多」按钮 | **关** |

以上功能都能在 **设置 → 橘小黑工作台 → 插件开关** 逐项开启或关闭，改动即时生效，无需重启。

## 设计原则

- **不改原生组件** — 不替换宿主的任何原生控件，只在不占位的地方追加入口
- **不用假数据** — 所有内容来自宿主真实服务，取不到就显示「—」
- **不拦截快捷键** — 宿主自带快捷键全部保持可用
- **性能优先** — 热点路径有短路闸门，流式输出时不触发强制重排
- **选择器耐久** — 依赖宿主 DOM 的地方用属性/子串匹配，不用构建期哈希类名

## 安装

```bash
# 克隆到本地
git clone https://github.com/Tangerine-Living/dsh-perfect-ui.git
cd dsh-perfect-ui

# 安装依赖并构建
npm install
node build.js
```

然后在 DeepSeek Harness 中：

1. 打开 **设置 → 插件**
2. 选择 **从本地安装**，指向本目录
3. 重启客户端

## 开发

```bash
node build.js      # 构建 dist/client.js
```

源码结构：

```
index.js       入口，装配所有功能（Host 半边）
model.js       模型选择器增强 + 推理强度面板
features.js    余额、工作区操作
settings.js    设置页（开关 + 背景颜色）
session.js     会话右键菜单
actions.js     工作区一键运行
theme-tokens.js  配色令牌
store.js       共享状态
build.js       构建脚本
```
